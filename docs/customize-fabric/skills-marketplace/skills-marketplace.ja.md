## Fabric のエージェントスキルマーケットプレイスとは？

エージェントスキルマーケットプレイスは、**スキル** と呼ばれる再利用可能な指示パックを見つけ、インストールし、管理するために Fabric に直接組み込まれた、中央集約型のレジストリおよび発見ハブです。

スキルは、特定のドメイン、言語、タスク向けに AI アシスタントの機能をカスタマイズする、専門的な動作プロファイルまたはアドオンとして機能します。概念的には、スキルは、システムプロンプトのガイドライン、機能の宣言、ツール制限を含む構造化されたマークダウンファイル（`SKILL.md`）として表現されます。マーケットプレイスは、グローバルな `skills.sh` レジストリから公開済みのスキルを取得し、開発者がカタログを検索し、プレビューを表示し、グローバル（ユーザー）またはローカル（プロジェクト）のスコープにインストールし、手動でプロンプトを複製することなくシームレスに最新の状態を保てるようにします。


## エージェントスキルマーケットプレイスを使うべきとき

次のような場合に、マーケットプレイスのスキルをワークフローに取り入れます。

* **エージェントの動作を専門化する**: 複雑な役割（vitest のユニットテスト作成者、コードのリファクタリング担当、データベース監査者など）のための専用スキルをエージェントに装備させることで、繰り返しのコンテキスト入力をなくします。
* **ワークフローを標準化する**: プロジェクトスコープのスキルをインストールすることで、すべてのチームメンバーのローカルエージェントが、同じスタイルガイドライン、リンティングルール、プルリクエスト構造に従ったコードを生成するようにします。
* **最適化されたプロンプトを活用する**: 特定のフレームワーク、ツール、API 向けに、コミュニティで検証され高度に最適化されたシステムプロンプトと指示セットを、自分で書いて改良することなくデプロイします。


## エージェントスキルマーケットプレイスを使う方法

### ステップ 1: アプリケーション設定を開く

左サイドバーの下部にある設定の歯車アイコンをクリックして、設定モーダルを開きます。

![アプリケーション設定を開く](../../assets/screenshots/skills-marketplace/1.png)

### ステップ 2: スキル設定に移動する

設定ナビゲーションサイドバーの「Skills」タブをクリックして、現在インストールされているエージェントスキルと構成オプションを表示します。

![スキル設定に移動する](../../assets/screenshots/skills-marketplace/2.png)

### ステップ 3: スキルマーケットプレイスを起動する

上部のヘッダーアクションストリップにある「Browse Marketplace」ボタンをクリックして、skills.sh マーケットプレイスのオーバーレイを開きます。

![スキルマーケットプレイスを起動する](../../assets/screenshots/skills-marketplace/3.png)

### ステップ 4: マーケットプレイスのカタログを検索する

マーケットプレイスのオーバーレイ上部にある検索入力フィールドに検索クエリ（例: 'git'）を入力して、キーワードでスキルをフィルターします。

![マーケットプレイスのカタログを検索する](../../assets/screenshots/skills-marketplace/4.png)

### ステップ 5: プレビューするスキルを選択する

左の列にある検索結果からスキルの行をクリックすると、右側のプレビューペインに、その README プレビュー、説明、バージョン、詳細が表示されます。

![プレビューするスキルを選択する](../../assets/screenshots/skills-marketplace/5.png)

### ステップ 6: スキルをインストールする

スキルプレビューペインの上部にある「Install」ボタンをクリックして、スキルをダウンロードし、環境に登録します。

![スキルをインストールする](../../assets/screenshots/skills-marketplace/6.png)

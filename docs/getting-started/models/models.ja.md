# モデル

Fabric は 2 種類のモデルに対応しています: **Fabric 独自のホスト型モデル**（API キー不要）と、自分の API キーで接続する **外部プロバイダー** です。これらを自由に組み合わせられます — 日々の作業には Fabric モデルを使い、特定の機能が必要なときは Anthropic や OpenAI を取り入れる、といった使い方が可能です。

---

## モデルの変更

![Models 設定パネル](../../assets/screenshots/settings/2_models.png)

**設定 → モデル** を開いて、モデルの構成を管理します。ここでは次のことができます:

- **ヘルパーモデル** の設定 — ファイルの編集やタブ名の提案など、バックグラウンドタスクに Fabric が使用する軽量モデル
- **サブエージェントモデル** の設定 — Fabric がサブエージェントを生成するときに使用するモデル（デフォルトではヘルパーモデルと同じ）
- 外部プロバイダーの API キーの追加
- 各プロバイダーで利用可能なモデルの確認と切り替え

設定を開かなくても、チャット入力バーの **モデルセレクター** から会話ごとにアクティブなモデルを直接切り替えることもできます。

---

## Fabric モデル

Fabric 独自のモデルは Fabric のインフラ上で動作し、サインインするとすぐに利用できます — API キーは不要です。

| モデル | 最適な用途 |
|-------|----------|
| **XLarge** | 難問、複雑な推論、アーキテクチャの決定 |
| **Large** | 機能開発、コードレビュー、大規模コンテキストのタスク |
| **Medium** | 日常的なコーディング、リファクタリング、説明 |
| **Small** | 簡単な編集、タブの命名、バックグラウンドのヘルパータスク |

すべての Fabric モデルは、ビジョン（画像入力）、ツール使用、そして最大 262K トークンの長いコンテキストウィンドウに対応しています。

## 外部 API プロバイダー

自分の API キーを接続すると、サポートされている任意のプロバイダーのモデルにアクセスできます。**設定 → モデル** に移動し、プロバイダーを見つけてキーを貼り付けると、セレクターでそのモデルが利用可能になります。

### Anthropic

Anthropic の Claude モデルは、推論、複雑な指示への対応、長文ドキュメントのタスクに優れています。

- **API キー**: [console.anthropic.com](https://console.anthropic.com) で取得できます
- **対応機能**: ビジョン、PDF 入力、ツール使用、拡張思考

利用可能なティア: Opus（最も高性能）、Sonnet（バランス型）、Haiku（高速・軽量）

### OpenAI

OpenAI の GPT モデルは広く使われており、エコシステム全体で十分にサポートされています。

- **API キー**: [platform.openai.com](https://platform.openai.com) で取得できます
- **対応機能**: ビジョン、PDF 入力、ツール使用、ウェブ検索、推論モード

高性能な推論モデルから、高速でコスト効率の高いオプションまで、さまざまなティアが利用可能です。

### Google

Google の Gemini モデルは、長いコンテキスト、マルチモーダル入力、コード実行が有効なタスクに優れています。

- **API キー**: [aistudio.google.com](https://aistudio.google.com) で取得できます
- **対応機能**: ビジョン、PDF、ツール使用、ウェブ検索、コード実行、推論

利用可能なティア: Pro（最も高性能）と Flash（高速・コスト効率重視）。

### OpenRouter

OpenRouter では、単一の API キーで幅広いサードパーティ製モデルにアクセスできます — 複数のアカウントを管理せずに、xAI、DeepSeek、Qwen などのモデルを試したい場合に便利です。

- **API キー**: [openrouter.ai](https://openrouter.ai) で取得できます
- **対応機能**: ツール使用、ストリーミング

### DeepSeek

DeepSeek は、低コストで強力なコーディングおよび推論モデルを提供しています。

- **API キー**: [platform.deepseek.com](https://platform.deepseek.com) で取得できます
- **対応機能**: ツール使用、推論（オン/オフ）、ストリーミング

### Cerebras

Cerebras はカスタムハードウェア上で推論を実行し、非常に高速なトークン生成速度を実現します。

- **API キー**: [cloud.cerebras.ai](https://cloud.cerebras.ai) で取得できます
- **対応機能**: ツール使用、ストリーミング

### ローカルモデル

Fabric は、ローカルで実行されているモデルサーバー（Ollama、LM Studio、vLLM、LocalAI、その他の OpenAI 互換エンドポイント）に接続できます。API キーは不要です — Fabric はマシン上で実行中のものを自動検出します。

- **セットアップ**: ローカルサーバーを起動し、設定 → モデル で **Local** を選択します
- Fabric は一般的なポートを自動的に調べ、利用可能なモデルを一覧表示します

## 適切なモデルの選び方

いくつかの目安を紹介します:

- **複雑なタスク**（アーキテクチャ、難問のデバッグ、マイグレーションの作成）には — Large または XLarge ティアのモデルを使用します。低速でコストはかかりますが、ミスが少なくなります。
- **日常的なタスク**（簡単な編集、質問への回答、再フォーマット）には — Medium または Small モデルの方が高速で安価でありながら、品質の低下はありません。
- **バックグラウンド作業**（ヘルパーおよびサブエージェントモデル）には — Fabric は自動的にコスト効率の高いモデルをデフォルトで使用します。自動処理のステップにより高い性能が必要な場合は、設定 → モデル で変更できます。
- **無料の選択肢** — Google（Gemini Flash）、Mistral、OpenRouter にはいずれも無料プランまたは無料モデルがあります。費用をかけずに始めるのに適しています。

!!! tip "会話の途中で切り替える"
    チャットバーのドロップダウンから、会話の途中でモデルを変更できます。新しいモデルは現在のコンテキストを引き継ぐため、最初からやり直す必要はありません。

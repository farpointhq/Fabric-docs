# Intégration

🚧 Le tutoriel vidéo est en cours de préparation.

La première fois que vous ouvrez Fabric, une courte intégration guidée vous configure et vous prépare à travailler. Elle apprend un peu sur ce sur quoi vous travaillez, vous aide à connecter un modèle d'IA et vous offre une visite rapide de l'interface — pour que vous ne restiez pas devant un écran vide à vous demander par où commencer.

Vous pouvez **passer à tout moment** et entrer directement dans un projet si vous préférez explorer par vous-même.

---

## Le déroulement

L'intégration se fait en trois courtes phases.

### 1. Une conversation rapide

Fabric s'ouvre sur une configuration conviviale et conversationnelle. Vous pouvez **parler ou taper** — selon votre préférence (elle revient automatiquement à la saisie s'il n'y a pas de microphone). Elle pose quelques questions légères pour comprendre :

- Ce sur quoi vous travaillez et ce que vous voulez accomplir
- L'état actuel de votre projet
- Votre façon de travailler — votre rythme, et la quantité de détails et de contexte que vous attendez de l'assistant

C'est facultatif et rapide. Son seul but est d'aider Fabric à adapter son aide à vous dès le premier message. Vos réponses restent sur votre ordinateur.

### 2. Une courte visite de bienvenue

Ensuite, un bref carrousel présente quelques éléments essentiels :

- **Multi-Chat** — exécutez plusieurs conversations en parallèle, pour continuer à travailler pendant que l'IA travaille.
- **Raccourcis** — une poignée des raccourcis clavier les plus utiles pour aller vite.
- **Confidentialité** — ce qui est collecté (des analyses d'utilisation de base) et, surtout, ce qui n'est jamais collecté (vos prompts, messages et fichiers). Les analyses peuvent être désactivées dans les paramètres.

### 3. Connecter un modèle et ouvrir un projet

Enfin, une visite guidée à cliquer vous accompagne à travers les deux choses nécessaires pour démarrer :

- **Connecter un modèle d'IA** — ajoutez une clé API d'un fournisseur comme Anthropic, OpenAI ou Google, ou pointez Fabric vers un modèle local. Il vous en faut au moins un avant de pouvoir discuter. Voir [Modèles](../models/models.md).
- **Ouvrir un dossier de projet** — choisissez le dossier dans lequel vous voulez travailler (un dossier vide convient).

Chemin faisant, la visite met en évidence les parties clés de l'interface pour que vous sachiez où se trouve chaque chose :

- L'**Explorateur de fichiers** pour parcourir votre projet
- L'**Historique de chat**, où chaque conversation est enregistrée et réouvrable
- Le panneau **Base de données**
- Les **Paramètres**
- La **zone de saisie du chat** en bas — votre espace de travail principal — ainsi que le sélecteur de modèle

---

## Quand c'est terminé

Une fois l'intégration terminée (ou passée), vous êtes entièrement configuré : un projet est ouvert, au moins un modèle d'IA est connecté, et vous vous repérez parmi les principaux panneaux. À partir de là, vous pouvez démarrer une conversation, poser des questions sur votre base de code ou lancer votre première tâche.

Vous voulez la refaire plus tard ? Vous pouvez **recommencer l'intégration** depuis les **Paramètres**.

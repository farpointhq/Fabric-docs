# オンボーディング

🚧 ビデオチュートリアルは作成中です。

Fabric を初めて開くと、短いガイド付きのオンボーディングがあなたをセットアップし、作業の準備を整えます。あなたが取り組んでいることを少し学び、AI モデルの接続を助け、インターフェースの簡単なツアーを行います。空の画面を前にどこから始めればいいか悩むことはありません。

自分のペースで探索したい場合は、**いつでもスキップ** してプロジェクトに直接入れます。

---

## 流れ

オンボーディングは 3 つの短いフェーズで進みます。

### 1. 簡単な会話

Fabric は、親しみやすい会話形式のセットアップで始まります。**話す** か **入力する** か、好きな方を選べます（マイクがない場合は自動的に入力にフォールバックします）。次のことを理解するために、いくつかの軽い質問をします：

- あなたが取り組んでいることと、達成したいこと
- プロジェクトの現在の状態
- 作業の好み — ペース、そしてアシスタントにどのくらいの詳細やコンテキストを求めるか

これは任意で手軽です。唯一の目的は、最初のメッセージから Fabric があなたに合わせて支援できるようにすることです。回答はあなたのコンピューターに留まります。

### 2. 短いウェルカムツアー

次に、簡単なカルーセルがいくつかの要点を紹介します：

- **マルチチャット** — 複数の会話を並行して実行し、AI が作業している間もあなたが作業を続けられます。
- **ショートカット** — すばやく操作するための、最も便利なキーボードショートカットの一部。
- **プライバシー** — 収集されるもの（基本的な使用状況の分析）と、重要な点として、決して収集されないもの（あなたのプロンプト、メッセージ、ファイル）。分析は設定でオフにできます。

### 3. モデルを接続してプロジェクトを開く

最後に、ガイド付きのクリック操作ツアーが、開始に必要な 2 つのことを案内します：

- **AI モデルを接続する** — Anthropic、OpenAI、Google などのプロバイダーの API キーを追加するか、ローカルモデルを指定します。チャットを始める前に少なくとも 1 つ必要です。[モデル](../models/models.md) を参照してください。
- **プロジェクトフォルダを開く** — 作業したいフォルダを選びます（空のフォルダでも構いません）。

その途中で、ツアーはインターフェースの主要な部分をハイライトし、すべてがどこにあるか分かるようにします：

- プロジェクトを閲覧する **ファイルエクスプローラー**
- すべての会話が保存され、再び開ける **チャット履歴**
- **データベース** パネル
- **設定**
- 一番下の **チャット入力** — あなたのメインの作業スペース — とモデルセレクター

---

## 完了したら

オンボーディングを終える（またはスキップする）と、すべての準備が整います。プロジェクトが開かれ、少なくとも 1 つの AI モデルが接続され、主要なパネルの場所も分かっています。ここから会話を始めたり、コードベースについて質問したり、最初のタスクに着手したりできます。

後でもう一度やり直したいですか？ **設定** から **オンボーディングをやり直す** ことができます。

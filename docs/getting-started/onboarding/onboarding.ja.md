# オンボーディング：Visr に会う

## Fabric のオンボーディングとは？

Fabric を初めて開くと、**Visr**（「wiser（賢い）」と韻を踏みます）が出迎えます。これは、あなたが実際に行う作業に合わせて Fabric を調整する、音声優先のセットアップエージェントです。クリックして進むツアーの代わりに、短い会話をします。あなたが取り組んでいることを話すと、Visr はプロジェクトと作業の好みについていくつか手早く質問し、話している間に、すでに答えられる質問を省くために、あなたの公開情報やディスク上の情報を静かに調査します。終わると、Visr はそのプロジェクト向けに構築されたワークスペースを開きます。多くの場合、最初のファイルがすでにスキャフォールドされ、開発サーバーが起動した状態です。つまり、Fabric で最初に目にする画面は、空白のページではなく、あなた自身のプロジェクトです。

すべては音声優先ですが、入力でも同じように機能し、いつでも空白のワークスペースに直接スキップできます。

## オンボーディングを使うべき場面

オンボーディングは、次のような場合に最も役立ちます。

* **初回起動ですばやくセットアップする**：インストール後に Fabric を初めて開いたとき、自動的に始まります。
* **まったく新しいプロジェクトを立ち上げる**：手作業で組み立てるのではなく、会話を通じて Fabric に新しいワークスペースを作成・調整してほしいときに、再実行します。
* **Fabric にあなたのコンテキストを学ばせる**：Visr が集める事実 — あなたのスタック、対象ユーザー、好む詳細度 — は、その後の Fabric の提案をパーソナライズします。

## オンボーディングの使い方

### ステップ 1：Visr に挨拶する

初回起動時、Visr は光るオーブの上で自己紹介し、シンプルな質問で始めます。*「それで、何をしたいですか？」* オーブは聞いたり話したりするのに合わせて反応します。話すか、ボックスに返事を入力して答えます。プライバシーに関する一文が、バックグラウンドの調査はあなたのマシン上にとどまり、いつでも停止できることを明記しています。

![初回起動時に Visr が出迎える](../../assets/screenshots/onboarding/1.png)

### ステップ 2：取り組んでいることを Visr に伝える

プロジェクトを自分の言葉で説明します（「習慣トラッカーの Web アプリ、ほぼ個人的なプロジェクト」）。話している間に、左側のバックグラウンド調査パネルが埋まっていきます。Visr があなたについて見つけたこと（名前、役割、何を作るか）を示す「Done（完了）」カードです。これにより、Visr はどの言語やフレームワークをよく使うかなど、すでに答えられる質問を省けます。調査はローカルにとどまり、いつでも停止できます。

![Visr がバックグラウンドであなたを調査する](../../assets/screenshots/onboarding/2.png)

### ステップ 3：詳細を確認する

Visr が学んだ各事項は、右側に小さな事実カードとして表示されます — 「趣味／個人」「自分だけ」などです。Visr は詳細をあなたに読み返すので、それに基づいて動く前に何でも修正できます。

![Visr があなたを理解するにつれて事実が積み重なる](../../assets/screenshots/onboarding/3.png)

### ステップ 4：Visr にセットアップを提案させる

十分に把握すると、Visr は質問をやめて提案を始めます。調査で見つけたことを織り込みながら：*「…React と TypeScript での以前の作業に基づいて、そのようにセットアップしましょうか？」* 確認するか、別の方向へ導きます。

![Visr が見つけた内容に基づいてスタックを提案する](../../assets/screenshots/onboarding/4.png)

### ステップ 5：ワークスペースが構築されるのを見る

Visr は Fabric に引き継ぎ、Fabric が実際にプロジェクトをスキャフォールドします。ファイルツリーを作成し、スターターファイルを書き、依存関係をインストールします。左側でファイルエクスプローラーが埋まっていく間、チャットで計画が実行される様子を見られます。

![Fabric がプロジェクトをスキャフォールドする](../../assets/screenshots/onboarding/5.png)

### ステップ 6：構築を始める

完了すると、動作するワークスペースに到着します。左側にプロジェクトファイル、右側に実行中のアプリのライブプレビュー、そしてチャットに検証の要約（インストール完了、開発サーバー起動、簡単なスモークテスト合格）があります。ここからは通常の Fabric です。会話を続けて次の機能を追加しましょう。

![ライブプレビュー付きの完成したワークスペース](../../assets/screenshots/onboarding/6.png)

## 話す代わりに入力する

読んで入力する方が好みですか？ オンボーディング画面の上部にある **Speak / Type（話す／入力）** と **Hear / Read（聞く／読む）** のトグルを使って、入力モードと出力モードを別々に切り替えられます。すべて同じように機能します — オーブ、調査パネル、事実カード、そして引き継ぎも。

## オンボーディングのスキップとやり直し

* **スキップする**：いつでも **Skip — open a project（スキップ — プロジェクトを開く）** を選ぶと、空白のワークスペースに直接移動するか、既存のフォルダを開けます。
* **後でやり直す**：**設定 → Companion → オンボーディングをやり直す** を開き、**Start onboarding again（オンボーディングをもう一度開始）** を選びます。アプリが再起動し、ウェルカムフローを最初から実行します。会話で Visr に伝えた内容はクリアされますが、バックグラウンドスキャンが推測したあなたに関する事実は保持されます。

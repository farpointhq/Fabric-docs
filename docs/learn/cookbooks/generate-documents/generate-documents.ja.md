# ドキュメント生成（Word、PowerPoint、PDF）

**所要時間:** 15〜30 分  
**難易度:** 初級  
**作るもの:** 1 つのソースコンテンツから、洗練された `.docx`、`.pptx`、`.pdf` ファイルを一度に生成するワークフロー。レポート、スライドデッキ、印刷対応の PDF を、すべて同じ素材から作ります。

---

## 概要

Fabric は標準では Office ドキュメントを生成しません。組み込みの「Word にエクスポート」ボタンはありません。その代わりに *持っている* のがスキルシステムです。[スキルマーケットプレイス](../../../customize-fabric/skills-marketplace/skills-marketplace.md) からドキュメント生成スキルをインストールすることで、Fabric に本物の `.docx`、`.pptx`、`.pdf` ファイルを作成する能力を与えられます。そうすれば、1 つの会話から 3 つの形式すべてを生成するよう依頼できます。

このクックブックでは、そのセットアップ方法と、複数形式の生成を 1 つのワークフローで実行する方法を示します。

---

## ステップ 1: ドキュメントスキルをインストールする

**設定 → スキル** を開き、**Browse Marketplace** をクリックして、ドキュメント生成スキルを検索します。次をカバーするスキルを探します：

- **docx** — Microsoft Word ドキュメント
- **pptx** — PowerPoint プレゼンテーション
- **pdf** — PDF の作成（およびフォーム入力／結合）

必要なものをインストールします。インストールすると、タスクがその形式を必要とするときに Fabric が自動的に呼び出せます。名前で呼び出す必要はありません。

!!! tip "3 つすべてをインストールする"
    一度の処理で本当の複数形式出力を望むなら、3 つのスキルを最初にすべてインストールしてください。AI はスキルを持っている形式しか生成できないため、docx、pptx、pdf が利用可能であることが、下記の単一プロンプトのワークフローを可能にします。

---

## ステップ 2: ソースコンテンツを準備する

ドキュメントが *何についてのもの* かを決め、Fabric に素材を渡します。次のいずれかでかまいません：

- 添付するドキュメントやメモ（クリップまたはドラッグ＆ドロップ）
- プロジェクトにすでにあるコンテンツ（Markdown ファイル、データセット）
- あるいはプロンプト内の説明だけ

たとえば、第 2 四半期の実績をまとめた `quarterly-summary.md` を添付するか、要点を直接貼り付けます。

ソースコンテンツが良いほど、3 つの出力すべてが良くなります。出力は元になった素材の品質を超えられません。

---

## ステップ 3: 3 つの形式すべてを一度に依頼する

スキルがインストールされ、コンテンツが準備できたら、3 つの成果物を説明する 1 つのリクエストを出します：

```
添付の quarterly-summary.md を使って、./output に 3 つのドキュメントを作成してください。

1. Word レポート (quarterly-report.docx) — 完全な文章、各セクションの見出し、
   主要指標のサマリーテーブル。
2. PowerPoint デッキ (quarterly-deck.pptx) — タイトルスライド 1 枚に加え、
   セクションごとに 1 枚、簡潔な箇条書き、そして指標テーブルを独立した 1 枚に。
3. PDF (quarterly-onepager.pdf) — 最も重要な 3 つの要点をまとめた
   1 ページのエグゼクティブサマリー。

3 つすべてでメッセージの一貫性を保ってください。
```

Fabric は各成果物を順に処理し、形式ごとに対応するスキルを呼び出します。すべてが 1 つの会話なので、3 つのドキュメントは互いに一貫した状態を保ちます。同じ数値、同じ枠組みで、各形式の強み（Word は文章、スライドは箇条書き、ワンページャーは簡潔さ）に合わせて適応されます。

---

## ステップ 4: 出力を確認する

エージェントモードでは、Fabric はファイルをプロジェクトに書き込みます。開いて確認します：

- `.docx` が Word で適切な見出しと本物のテーブルを伴ってきれいに開く
- `.pptx` が PowerPoint で想定どおりのスライドで開く
- `.pdf` がきれいな 1 ページとしてレンダリングされる

何かおかしければ、そう伝えるだけです：

```
デッキはスライドあたりのテキストが多すぎます。各スライドを最大 3 つの箇条書きに減らし、
詳細はスピーカーノートに移してください。
```

Fabric は最初からやり直すことなく、該当するファイルを再生成します。

---

## ステップ 5: 他に手を触れず 1 つの形式だけを反復する

各ドキュメントは別々のファイルなので、独立して改善できます：

```
Word レポートと PDF はそのままにしてください。PowerPoint には、
次のステップと 3 つのアクションアイテムを記したクロージングスライドを追加してください。
```

---

## バリエーション

**単一形式** — 3 つすべてを生成する必要はありません。必要なスキルだけをインストールし、その形式だけを依頼します。

**テンプレートから** — 既存の `.docx` や `.pptx` を添付し、新しいドキュメントでその構造とスタイルに従うよう Fabric に頼みます。

**データ駆動** — [データベース](../../../using-fabric/app/databases/databases.md) に接続するか、スプレッドシートを添付して、レポート、デッキ、PDF に数値を直接取り込むよう Fabric に頼みます。

**既存の PDF に入力する** — PDF スキルは新しい PDF を作成するだけでなく、フォーム入力やファイルの結合もできます。生成したコンテンツでテンプレートを埋めるのに便利です。

---

## ヒント

**プロンプトの前にインストールする。** AI はスキルを持っていない形式を生成できません。`.pptx` のリクエストがプレーンテキストで返ってきたら、おそらく pptx スキルがまだインストールされていません。

**ファイル名と場所を明示する。** 各ファイルの名前と置き場所を Fabric に正確に伝え、出力が想定どおりの場所に着地するようにします。

**各形式の形を説明する。** Word は文章と見出しを、スライドは短い箇条書きを、ワンページャーは徹底した簡潔さを求めます。それぞれの構造を明示すると、「デッキとドキュメントを作って」よりはるかに良い結果が得られます。

**単一の信頼できる情報源を保つ。** すべての形式を 1 つの会話で同じソースコンテンツから生成することが、一貫性を保つ鍵です。別々のセッションで生成すると、内容がずれていくことがあります。

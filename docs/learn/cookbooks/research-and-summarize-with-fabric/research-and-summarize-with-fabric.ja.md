# Fabric でリサーチと要約を行う

**所要時間:** セットアップ5分  
**難易度:** 初級  
**作成するもの:** あらゆる種類のドキュメントやウェブコンテンツを — Fabric から離れることなく — 読み、調査し、要約するためのワークフロー。

---

## 概要

Fabric のアプリ内ブラウザ、ファイル添付、永続的な会話コンテキストにより、Fabric は有能なリサーチ環境となります。このクックブックでは、3つのよくあるリサーチワークフローを取り上げます。アップロードしたドキュメントの要約、組み込みブラウザを使った調査、複数の情報源にまたがる継続的な要約の作成です。

---

## ワークフロー1: ドキュメントを要約する

長いドキュメントから価値を引き出す最も速い方法は、それを添付して直接質問することです。

**対応形式:** PDF、プレーンテキストファイル、Markdown、コードファイル、およびほとんどのドキュメント形式。

### ステップ1: ドキュメントを添付する

チャット入力バーの**ペーパークリップアイコン**をクリックし、ファイルを選択します。テキストフィールドの上にチップとして表示されます。

### ステップ2: 焦点を絞った質問をする

「これを要約して」ではなく、本当に必要なことを尋ねます。

```
この論文の主要な論点は何で、それを裏付けるためにどんな証拠を使っていますか？
```

```
これは契約書です — 解約条項はどうなっていて、必要な通知期間はどれくらいですか？
```

```
この会議の議事録から、すべてのアクションアイテムと担当者を抽出してください。
```

具体的な質問には具体的な答えが返ってきます。「これを要約して」では、ありきたりな要約しか得られません。

### ステップ3: フォローアップする

要約は出発点です。さらに深掘りするためにフォローアップしましょう。

```
方法論に限界があると言いましたが、それは何でしたか？
```

```
契約書の中に、異例なものや弁護士に確認すべきものはありますか？
```

Fabric は会話を通じてドキュメント全体をコンテキストに保持するため、必要なだけフォローアップの質問ができます。

---

## ワークフロー2: 組み込みブラウザでリサーチする

アプリ内ブラウザを使って、アプリを切り替えることなくウェブコンテンツを読み、それを直接会話に取り込みます。

### ステップ1: ブラウザを開く

左サイドバーの**ブラウザアイコン**をクリックするか、タブバーからブラウザタブに切り替えます。

### ステップ2: 情報源に移動する

アドレスバーに URL または検索クエリを入力します。Fabric のブラウザは通常のブラウザと同じように動作します — ドキュメントページ、記事、論文、その他あらゆる公開ウェブページに移動できます。

### ステップ3: Fabric にページを読むよう依頼する

チャットタブに切り替えて、こう尋ねます。

```
開いているページを読んで、要点を要約してください。
```

エージェントモードでは、Fabric があなたに代わってページを閲覧できます。

```
この製品の料金ページを見つけて、無料プランに何が含まれているか教えてください。
```

```
このライブラリの変更履歴を調べて、直近3バージョンで何が変わったか教えてください。
```

### ステップ4: 複数の情報源を比較する

ページ間を移動して、比較像を作り上げていきます。

```
この問題に対する3つの異なるアプローチを見せました。
それらの間のトレードオフは何ですか？
```

---

## ワークフロー3: 複数の情報源にまたがる継続的な要約を作成する

複数のドキュメントやページにまたがってより深いリサーチを行う場合は、単一のタブをリサーチセッションとして使い、コンテキストを少しずつ積み上げていきます。

### ステップ1: 専用のリサーチタブを開始する

新しいタブを開き（タブバーの **+** をクリック）、頭の中でそれをリサーチタブとして位置づけます。作業用のタブとは分けておきましょう。

### ステップ2: 情報源を1つずつ添付または閲覧する

各情報源を順番に会話に追加します。1つ追加するたびに、Fabric にそれを統合するよう依頼します。

```
これが2つ目の論文です。その方法論は最初のものと比べてどうですか？
```

```
これが3つ目の記事です。これまでに扱った内容を裏付けますか、それとも矛盾しますか？
```

### ステップ3: 統合を依頼する

情報源を一通り見終えたら、すべてにまたがる統合を依頼します。

```
これまでに読んだすべてを踏まえると、このトピックに関する現在の総意は何で、
まだ意見が分かれているのはどこですか？
```

```
このトピックについて1ページのブリーフィングを書く必要があります。
これまでに確認した情報源をもとに草案を作成してください。
```

### ステップ4: 会話が長くなったら Compact する

リサーチの会話は長くなりがちです。コンテキストインジケーターが会話のいっぱいになってきたことを示したら、**Compact** をクリックして、重要な発見をコンテキストに残しつつ、古いやり取りを要約しましょう。

---

## ヒント

**手早い質問にはテキストを直接貼り付ける。** 短い一節 — 1段落、いくつかの箇条書き — の場合は、ファイルを添付する必要はありません。テキストをメッセージに貼り付けて、その場で質問するだけです。

**特定の出力形式を依頼する。** 「主な主張を箇条書きのリストで教えて」や「これを1段落のエグゼクティブサマリーとして書いて」と伝えれば、すぐに使えるものが得られます。

**英語以外のコンテンツにも使う。** どんな言語のドキュメントでも添付して、Fabric に英語で（またはその逆で）要約するよう依頼できます。

**出力を保存する。** Fabric に要約をファイルに書き出すよう依頼します。*「この要約を `research-notes/paper-1-summary.md` として保存して」*。エージェントモードでは、プロジェクトフォルダにファイルを作成します。

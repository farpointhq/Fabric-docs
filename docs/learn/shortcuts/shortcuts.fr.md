# Raccourcis clavier

Une référence complète des raccourcis clavier dans Fabric. Vous les trouverez également dans **Paramètres → Raccourcis**.

---

## Discussion

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Envoyer le message | `↵` | `↵` |
| Appuyer-pour-parler (voix) | `Right ⌥` (maintenir) | `Right Alt` (maintenir) |
| Envoyer le dernier agent en arrière-plan | `⌘ B` | `Ctrl B` |

---

## Fenêtre et navigation

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Ouvrir les paramètres | `⌘ ,` | `Ctrl ,` |
| Fermer l'onglet | `⌘ W` | `Ctrl W` |
| Onglet / volet suivant | `⌘ ⌥ →` | `Alt →` |
| Onglet / volet précédent | `⌘ ⌥ ←` | `Alt ←` |
| Réduire le terminal | `⌘ \`` | `Ctrl \`` |
| Zoom avant | `⌘ +` | `Ctrl +` |
| Zoom arrière | `⌘ -` | `Ctrl -` |
| Réinitialiser le zoom | `⌘ 0` | `Ctrl 0` |
| Fermer la fenêtre modale / dialogue | `Esc` | `Esc` |

---

## Changement rapide

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Sélecteur de modèle | `⌘ Shift /` | `Ctrl Shift /` |
| Changer de mode | `⌘ .` | `Ctrl .` |
| Recherche par nom de fichier | `⌘ E` | `Ctrl E` |
| Recherche de contenu | `⌘ Shift E` | `Ctrl Shift E` |

---

## Recherche de fichiers

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Rechercher des fichiers | `⌘ F` | `Ctrl F` |
| Activer/désactiver la sensibilité à la casse | `⌘ I` | `Ctrl I` |
| Activer/désactiver les expressions régulières | `⌘ R` | `Ctrl R` |

---

## Éditeur

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Enregistrer le fichier | `⌘ S` | `Ctrl S` |
| Formater le document | `Shift ⌥ F` | `Shift Alt F` |
| Rechercher | `⌘ F` | `Ctrl F` |
| Remplacer | `⌘ H` | `Ctrl H` |
| Activer/désactiver le commentaire | `⌘ /` | `Ctrl /` |
| Annuler | `⌘ Z` | `Ctrl Z` |
| Rétablir | `⌘ Shift Z` | `Ctrl Y` |
| Aller à la ligne | `⌘ G` | `Ctrl G` |
| Tout sélectionner | `⌘ A` | `Ctrl A` |
| Indenter la ligne | `Tab` | `Tab` |
| Désindenter la ligne | `Shift Tab` | `Shift Tab` |
| Dupliquer la ligne | `Shift ⌥ ↑ / ↓` | `Shift Alt ↑ / ↓` |
| Déplacer la ligne vers le haut / le bas | `⌥ ↑ / ↓` | `Alt ↑ / ↓` |

---

## Terminal

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Nouveau terminal | `⌃ Shift \`` | `Ctrl Shift \`` |
| Diviser le terminal | `⌘ \` | `Ctrl \` |
| Coller dans le terminal | `⌘ V` | `Ctrl V` |
| Mettre le focus sur les onglets du terminal | `⌘ Shift \` | `Ctrl Shift \` |
| Mettre le focus sur le volet suivant | `⌥ ⌘ →` | `Alt →` |
| Mettre le focus sur le volet précédent | `⌥ ⌘ ←` | `Alt ←` |
| Fermer le terminal (onglets en focus) | `⌘ ⌫` | `Del` |

| Action | Touche |

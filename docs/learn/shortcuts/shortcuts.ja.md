# キーボードショートカット

Fabric のキーボードショートカットの完全なリファレンスです。**設定 → ショートカット** からも確認できます。

---

## チャット

| 操作 | Mac | Windows / Linux |
|--------|-----|-----------------|
| メッセージを送信 | `↵` | `↵` |
| プッシュ・トゥ・トーク（音声） | `Right ⌥`（長押し） | `Right Alt`（長押し） |
| 最新のエージェントをバックグラウンドへ送る | `⌘ B` | `Ctrl B` |

---

## ウィンドウとナビゲーション

| 操作 | Mac | Windows / Linux |
|--------|-----|-----------------|
| 設定を開く | `⌘ ,` | `Ctrl ,` |
| タブを閉じる | `⌘ W` | `Ctrl W` |
| 次のタブ / ペイン | `⌘ ⌥ →` | `Alt →` |
| 前のタブ / ペイン | `⌘ ⌥ ←` | `Alt ←` |
| ターミナルを折りたたむ | `⌘ \`` | `Ctrl \`` |
| ズームイン | `⌘ +` | `Ctrl +` |
| ズームアウト | `⌘ -` | `Ctrl -` |
| ズームをリセット | `⌘ 0` | `Ctrl 0` |
| モーダル / ダイアログを閉じる | `Esc` | `Esc` |

---

## クイックスイッチ

| 操作 | Mac | Windows / Linux |
|--------|-----|-----------------|
| モデルピッカー | `⌘ Shift /` | `Ctrl Shift /` |
| モードを切り替え | `⌘ .` | `Ctrl .` |
| ファイル名検索 | `⌘ E` | `Ctrl E` |
| コンテンツ検索 | `⌘ Shift E` | `Ctrl Shift E` |

---

## ファイル検索

| 操作 | Mac | Windows / Linux |
|--------|-----|-----------------|
| ファイルを検索 | `⌘ F` | `Ctrl F` |
| 大文字小文字の区別を切り替え | `⌘ I` | `Ctrl I` |
| 正規表現を切り替え | `⌘ R` | `Ctrl R` |

---

## エディタ

| 操作 | Mac | Windows / Linux |
|--------|-----|-----------------|
| ファイルを保存 | `⌘ S` | `Ctrl S` |
| ドキュメントをフォーマット | `Shift ⌥ F` | `Shift Alt F` |
| 検索 | `⌘ F` | `Ctrl F` |
| 置換 | `⌘ H` | `Ctrl H` |
| コメントを切り替え | `⌘ /` | `Ctrl /` |
| 元に戻す | `⌘ Z` | `Ctrl Z` |
| やり直す | `⌘ Shift Z` | `Ctrl Y` |
| 指定行へ移動 | `⌘ G` | `Ctrl G` |
| すべて選択 | `⌘ A` | `Ctrl A` |
| 行をインデント | `Tab` | `Tab` |
| 行のインデントを解除 | `Shift Tab` | `Shift Tab` |
| 行を複製 | `Shift ⌥ ↑ / ↓` | `Shift Alt ↑ / ↓` |
| 行を上 / 下へ移動 | `⌥ ↑ / ↓` | `Alt ↑ / ↓` |

---

## ターミナル

| 操作 | Mac | Windows / Linux |
|--------|-----|-----------------|
| 新規ターミナル | `⌃ Shift \`` | `Ctrl Shift \`` |
| ターミナルを分割 | `⌘ \` | `Ctrl \` |
| ターミナルに貼り付け | `⌘ V` | `Ctrl V` |
| ターミナルタブにフォーカス | `⌘ Shift \` | `Ctrl Shift \` |
| 次のペインにフォーカス | `⌥ ⌘ →` | `Alt →` |
| 前のペインにフォーカス | `⌥ ⌘ ←` | `Alt ←` |
| ターミナルを終了（タブにフォーカス時） | `⌘ ⌫` | `Del` |

---

## 差分ビューア

| 操作 | キー |
|--------|-----|
| ハイライトされた変更を承認 | `A` |
| ハイライトされた変更を破棄 | `D` |
| 前の変更へスクロール | `W` |
| 次の変更へスクロール | `S` |

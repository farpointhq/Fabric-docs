# Keyboard Shortcuts

A full reference of keyboard shortcuts in Fabric. You can also find these in **Settings → Shortcuts**.

---

## Chat

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Send message | `↵` | `↵` |
| Push-to-talk (voice) | `Right ⌥` (hold) | `Right Alt` (hold) |
| Send latest agent to background | `⌘ B` | `Ctrl B` |

---

## Window & Navigation

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Open Settings | `⌘ ,` | `Ctrl ,` |
| Close tab | `⌘ W` | `Ctrl W` |
| Next tab / pane | `⌘ ⌥ →` | `Alt →` |
| Previous tab / pane | `⌘ ⌥ ←` | `Alt ←` |
| Collapse terminal | `⌘ \`` | `Ctrl \`` |
| Zoom in | `⌘ +` | `Ctrl +` |
| Zoom out | `⌘ -` | `Ctrl -` |
| Reset zoom | `⌘ 0` | `Ctrl 0` |
| Close modal / dialog | `Esc` | `Esc` |

---

## Quick Switch

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Model picker | `⌘ Shift /` | `Ctrl Shift /` |
| Cycle mode | `⌘ .` | `Ctrl .` |
| File name search | `⌘ E` | `Ctrl E` |
| Content search | `⌘ Shift E` | `Ctrl Shift E` |

---

## File Search

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Search files | `⌘ F` | `Ctrl F` |
| Toggle case sensitive | `⌘ I` | `Ctrl I` |
| Toggle regex | `⌘ R` | `Ctrl R` |

---

## Editor

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| Save file | `⌘ S` | `Ctrl S` |
| Format document | `Shift ⌥ F` | `Shift Alt F` |
| Find | `⌘ F` | `Ctrl F` |
| Replace | `⌘ H` | `Ctrl H` |
| Toggle comment | `⌘ /` | `Ctrl /` |
| Undo | `⌘ Z` | `Ctrl Z` |
| Redo | `⌘ Shift Z` | `Ctrl Y` |
| Go to line | `⌘ G` | `Ctrl G` |
| Select all | `⌘ A` | `Ctrl A` |
| Indent line | `Tab` | `Tab` |
| Outdent line | `Shift Tab` | `Shift Tab` |
| Duplicate line | `Shift ⌥ ↑ / ↓` | `Shift Alt ↑ / ↓` |
| Move line up / down | `⌥ ↑ / ↓` | `Alt ↑ / ↓` |

---

## Terminal

| Action | Mac | Windows / Linux |
|--------|-----|-----------------|
| New terminal | `⌃ Shift \`` | `Ctrl Shift \`` |
| Split terminal | `⌘ \` | `Ctrl \` |
| Paste to terminal | `⌘ V` | `Ctrl V` |
| Focus terminal tabs | `⌘ Shift \` | `Ctrl Shift \` |
| Focus next pane | `⌥ ⌘ →` | `Alt →` |
| Focus previous pane | `⌥ ⌘ ←` | `Alt ←` |
| Kill terminal (tabs focused) | `⌘ ⌫` | `Del` |

---

## Diff Viewer

| Action | Key |
|--------|-----|
| Accept highlighted change | `A` |
| Discard highlighted change | `D` |
| Scroll to previous change | `W` |
| Scroll to next change | `S` |

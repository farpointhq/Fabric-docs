## Fabric のエージェントによるブラウザ操作とは

Fabric のエージェントブラウザを使用すると、AI アシスタントがあなたの代わりに直接 Web を閲覧し、データベースを検索し、構造化された情報を抽出できます。手動でコピー＆ペーストする代わりに、エージェントはプログラムでページを開き、DOM スクレイピングスクリプトを実行し、スナップショットを取得し、調査結果をチャット履歴に直接まとめることができます。


## エージェントによるブラウザ操作を使うタイミング

AI アシスタントに次のことをさせたい場合に、Fabric のエージェントブラウザを使用します。

* **市場調査や製品調査を行う**: エージェントにオンラインストア（Amazon など）を検索させ、価格、仕様、レビューを比較させます。
* **サイトからデータを抽出する**: エージェントにリスティング、ドキュメントのテーブル、API エンドポイントをクロールさせます。
* **複数ステップのワークフローを自動化する**: エージェントにフォームの操作、セレクターのクリック、複数ページのシーケンスの追跡を行わせて、データを収集させます。


## エージェントによるブラウザ操作の使い方

### ステップ 1: エージェント対応モデルを選択する

エージェントによるツール使用を有効にするには、チャットツールバーのメインのモデルセレクターをクリックします。

![エージェント対応モデルを選択する](../../../assets/screenshots/agentic-browser/1.png)

### ステップ 2: Fabric XLarge モデルを選択する

自律的な Web ブラウジングを有効にするには、'Fabric XLarge' モデル（またはブラウザツールの実行をサポートする任意のモデル）を選択します。

![Fabric XLarge モデルを選択する](../../../assets/screenshots/agentic-browser/2.png)

### ステップ 3: ブラウジングのプロンプトを送信する

トップ 3 のモニターを見つけるなど、特定の情報を Amazon で調べるようエージェントに依頼します。チャットコンポーザーにリクエストを入力します。

![ブラウジングのプロンプトを送信する](../../../assets/screenshots/agentic-browser/3.png)

### ステップ 4: リクエストを送信する

Enter キーを押すか送信をクリックして、プロンプトを送信します。Fabric はブラウザツールを起動し、分割ペインの Webview を開き、ナビゲーションとスクレイピングのスクリプトの実行を開始します。

![リクエストを送信する](../../../assets/screenshots/agentic-browser/4.png)

### ステップ 5: 統合された結果を待って確認する

Fabric は Web ページの操作を内部で自動的に処理します。完了すると、スクレイピングした製品リスティングを統合し、トップ 3 のモニターをチャットに直接表示します。

![統合された結果を待って確認する](../../../assets/screenshots/agentic-browser/5.png)

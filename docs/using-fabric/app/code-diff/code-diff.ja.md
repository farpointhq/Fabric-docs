# コード差分

AI があなたのファイルを編集するとき、何も無断で書き込まれることはありません。提案されたすべての変更はインタラクティブな差分ビューアに表示され、そこで内容を確認し、採用したい部分を承認し、不要な部分を拒否し、実際にディスクに書き込まれる内容を完全にコントロールできます。

---

## 仕組み

![提案された変更を表示するインタラクティブな差分ビューア](../../../assets/screenshots/code-diff/1.png)

AI が編集ツールを使うと、Fabric は元のファイルと提案されたバージョンを並べて取り込み、その差分を提示します。何が追加され、何が削除されるのかを文脈の中で確認し、ハンク（変更のまとまり）ごとに何を残すかを決められます。

あなたが操作するまで何も確定しません。個々の変更を承認したり、拒否したり、一度にすべて承認したり、すでに下した決定を取り消したりできます。

---

## 変更の承認と拒否

差分ビューアは **ハンク** 単位で動作します。ハンクとは、ファイル内の連続した変更ブロックです。各ハンクに対して、次の操作ができます：

- 変更を **承認** する（✓）— 提案された編集を残します
- 変更を **拒否／元に戻す**（✗）— 破棄して元の内容を残します
- その箇所で **ファイルを開く** — エディタ内の正確な位置にジャンプします

ファイル単位のコントロールから、そのファイル内の **すべて** の変更を一度に承認または拒否することもできます。気が変われば決定を取り消せます。ビューアは取り消し履歴を保持するので、何も固定されてしまうことはありません。

---

## キーボードショートカット

差分ブロックにフォーカスがあるとき、マウスを使わずに操作できます：

| キー | 操作 |
|-----|------|
| `A` | ハイライトされた変更を承認 |
| `D` | ハイライトされた変更を破棄／拒否 |
| `W` | 前の変更へスクロール |
| `S` | 次の変更へスクロール |

これにより、大量の編集を素早くレビューできます。`W` / `S` で移動し、`A` / `D` で判断します。

---

## 複数ファイルにまたがる変更のレビュー

![変更されたすべてのファイルをファイル単位の承認・取り消しコントロールとともに一覧表示するレビュー画面](../../../assets/screenshots/code-diff/2.png)

AI が 1 つのタスクで複数のファイルを編集した場合、変更はファイルごとに作業できるようグループ化されます。サイドパネルに変更された各ファイルが独自の承認／拒否コントロールとともに一覧表示されるため、ファイル全体を一度に承認することも、詳しく見たい箇所で個々のハンクに踏み込むこともできます。

---

## なぜ差分をレビューするのか

- **意図しない編集を見つける。** AI は時に予想以上に手を加えることがあります。差分は、それが保存される前に気づける場所です。
- **部分的な変更を残す。** すべてか無かである必要はありません。良いハンクを承認し、残りを拒否できます。
- **何が変わったかを理解する。** 差分を読むことは、AI が何を、なぜ行ったのかを正確に理解する最速の方法です。

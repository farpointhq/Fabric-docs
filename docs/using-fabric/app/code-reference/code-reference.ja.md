特定のコードについて AI に質問したいとき、その全体をチャットに貼り付ける必要はありません。Fabric では、ファイルの正確な行を **参照** できます。行を選択してコンパクトなタグとしてチャットに取り込めば、AI はあなたがどのコードを指しているのかを正確に把握します。

---

## 仕組み

エディタでファイルを開き、話題にしたい **行を選択** します。それから次の 2 つの方法のいずれかでチャットに取り込みます：

**コピー＆ペースト** — 選択した行をコピーし（`Ctrl/Cmd C`）、チャット入力欄に貼り付けます（`Ctrl/Cmd V`）。生のコードをメッセージに放り込む代わりに、Fabric はそれをファイル名と行範囲を示す小さな **リファレンスピル** に変えます。たとえば `utils.ts:42-50` のように。

**右クリック → チャットに追加** — エディタで選択したコードを右クリックし、**Add to previous chat（前のチャットに追加）** を選びます。エディタを離れることなく、リファレンスピルがチャット入力欄にすぐに追加されます。

どちらの方法でも、貼り付けられたコードの塊ではなく、メッセージの中にすっきりとしたピルが残ります。その周りに質問を入力し続けられますし、好きなだけ参照を追加できます。

---

## コードに戻る

リファレンスピルは双方向のリンクです。入力欄でも、後でチャット履歴の中でも、**クリックする** と Fabric がそのファイルを開き、参照された行までスクロールします。これにより、数週間後に会話を再び開いたときでも、話していた内容を正確に見直すのが簡単になります。

---

## なぜ重要なのか

コードを貼り付ける代わりに参照することは、いくつかの現実的な問題を解決します：

- **コンテキストをクリーンに保つ。** 参照はファイル名と行範囲だけなので、会話（や AI のコンテキストウィンドウ）を大きなコードブロックで埋め尽くしません。これによりレスポンスが速く、安くなります。[コストの追跡](../../core-ai-workflows/cost-tracking/cost-tracking.md) を参照してください。
- **常に正確。** AI はレスポンス時にファイルから実際の行を読むため、以前に貼り付けた古いコピーではなく、本物の最新のコードを見ます。
- **ナビゲートが簡単。** すべてのピルがクリック可能なので、チャット履歴がコードベースへ戻るブックマークの役割も果たします。
- **正確。** 「そのファイルの上の方にある関数」ではなく、AI はあなたが指し示した正確な行を受け取ります。

---

## スマートなコピー＆ペースト

うれしいのは、コピー＆ペーストが期待どおりに、しかもよりスマートに動くことです。Fabric のエディタからコードをコピーしてチャットに貼り付けると、自動的にリファレンスピルになります。そして同じコードを Fabric の外のどこかに貼り付けても、通常のコードとして届くので、何も失われません。Fabric の内部では軽量な参照を、それ以外のどこでも通常のコピー＆ペーストを得られます。

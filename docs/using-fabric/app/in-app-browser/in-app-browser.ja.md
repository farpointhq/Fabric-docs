## Fabric のアプリ内ブラウザとは

Fabric のアプリ内ブラウザを使用すると、ワークスペース内で直接 Web を閲覧したり、ドキュメントを読んだり、外部リソースを操作したりできます。ブラウザタブはプロンプトセッションやファイルと並んで動作するため、エディタと外部 Web ブラウザの間で絶えずコンテキストを切り替えることなく、リサーチをコンテキスト内に保つことができます。

ブラウザタブは完全なナビゲーションコントロールと安全な状態の分離をサポートし、さらにチャットパネルのすぐ隣にドッキングして、並べてプロンプト入力や参照を行うこともできます。


## Fabric のアプリ内ブラウザを使うタイミング

次のような場合に Fabric のアプリ内ブラウザを使用します。

* **ドキュメントを並べて読む**: アクティブなチャットセッションのすぐ隣に、ドキュメントページ（React、Tailwind、ライブラリの API ドキュメントなど）を開いてドッキングします。
* **Web アプリのテストと表示**: ローカル開発サーバー（例: `http://localhost:3000`）やリモートの Web リソースをワークスペースのタブ内で確認します。
* **Web リサーチをセッション内に保つ**: ブラウザタブを関連するプロンプトやチャットとグループ化しておき、リソースを見失わないようにします。


## Fabric のアプリ内ブラウザの使い方

### ステップ 1: 新しいタブアイコンを右クリックする

タブバーの末尾にあるプラス（+）アイコンを右クリックして、新しいタブのオプションのコンテキストメニューを開きます。

![新しいタブアイコンを右クリックする](../../../assets/screenshots/in-app-browser/1.png)

### ステップ 2: 'New Browser Tab' を選択する

'New Browser Tab' メニュー項目をクリックして、まっさらなアプリ内 Web ブラウザタブを開き、Web サイト（例: `https://www.amazon.com/`）に移動します。

![New Browser Tab を選択する](../../../assets/screenshots/in-app-browser/2.png)

### ステップ 3: 読み込まれた Web ページを表示する

Web サイトは、Fabric ワークスペース内の安全でサンドボックス化された Webview ペイン内に直接読み込まれます。

![読み込まれた Web ページを表示する](../../../assets/screenshots/in-app-browser/3.png)

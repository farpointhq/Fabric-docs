## What is In-App Browser in Fabric?

The In-App Browser in Fabric allows you to browse the web, read documentation, and interact with external resources directly within your workspace. Because the browser tabs run alongside your prompt sessions and files, you can keep research in-context without constantly context-switching between your editor and external web browsers.

Browser tabs support full navigation controls, secure state isolation, and can even be docked directly next to your chat panel for side-by-side prompting and reference.


## When to use In-App Browser in Fabric

Use the in-app browser in Fabric when you want to:

* **Read Documentation Side-by-Side**: Open and dock documentation pages (like React, Tailwind, or library API docs) right next to your active chat session.
* **Test and View Web Apps**: Check local dev servers (e.g., `http://localhost:3000`) or remote web resources inside your workspace tabs.
* **Keep Web Research in Your Session**: Keep browser tabs grouped with relevant prompts and chats so you don't lose track of resources.


## How to use In-App Browser in Fabric

### Step 1: Right-Click the New Tab Icon

Right-click the plus (+) icon at the end of the tab bar to open the new tab options context menu.

![Right-Click the New Tab Icon](../../../assets/screenshots/in-app-browser/1.png)

### Step 2: Select 'New Browser Tab'

Click the 'New Browser Tab' menu item to open a clean in-app web browser tab and navigate to a website (e.g., `https://www.amazon.com/`).

![Select 'New Browser Tab'](../../../assets/screenshots/in-app-browser/2.png)

### Step 3: View the Loaded Webpage

The website loads directly inside the secure, sandboxed Webview pane within your Fabric workspace.

![View the Loaded Webpage](../../../assets/screenshots/in-app-browser/3.png)

## Fabric におけるマルチエージェントワークフロー（サブエージェント）とは？

サブエージェントを使うと、親チャットセッションが、並列かつ独立した作業トラックを、特定タスクに特化したバックグラウンドの LLM エージェントに委譲できます。これにより、複雑なタスク分解（例えば、あるエージェントにコード品質をレビューさせ、別のエージェントにセキュリティ問題を確認させ、3 つ目のエージェントにバグを探させる、といったこと）を実行し、それらの調査結果を 1 つの会話スレッドにまとめて取り込むことが可能になります。


## マルチエージェントワークフロー（サブエージェント）を使うべき場面

Fabric でサブエージェントを使うのは、次のようなことを行いたい場合です。

* **並列タスクの実行**: 同時並行のプロセス（例: セキュリティ監査、パフォーマンスプロファイリング、テスト生成）を独立したエージェントに委譲します。
* **専門的な知見の活用**: 特定のドメインに合わせた複数のバックグラウンドプロンプトを同時に実行します。
* **複雑なコードベースのレビュー**: サブエージェントにワークスペースのさまざまな側面をスキャンさせ、整理された統一レポートに集約させます。


## マルチエージェントワークフロー（サブエージェント）の使い方

### ステップ 1: ファイルエクスプローラーを開く

左側のナビゲーションバーにあるファイルエクスプローラーパネルを開き、プロジェクトファイルにアクセスします。

![ファイルエクスプローラーを開く](../../../assets/screenshots/sub-agents/1.png)

### ステップ 2: プロジェクトファイルを開く

ファイル（例: `template.yaml`）を開いて、その内容を別のエディタタブで表示します。

![プロジェクトファイルを開く](../../../assets/screenshots/sub-agents/2.png)

### ステップ 3: チャットタブに戻る

参照用にファイルタブを開いたままにし、タブバーの「Chat」タブをクリックしてメインの会話セッションに戻ります。

![チャットタブに戻る](../../../assets/screenshots/sub-agents/3.png)

### ステップ 4: モデルセレクターを開く

チャットツールバーのメインのモデルセレクターをクリックします。

![モデルセレクターを開く](../../../assets/screenshots/sub-agents/4.png)

### ステップ 5: Fabric XLarge モデルを選択する

サブエージェントのオーケストレーションのツール使用をサポートするモデル（「Fabric XLarge」など）を選択します。

![Fabric XLarge モデルを選択する](../../../assets/screenshots/sub-agents/5.png)

### ステップ 6: チャットでサブエージェントにプロンプトを送る

Fabric に対して 3 つのサブエージェント（1 つはコードレビュー用、1 つはデバッグ用、1 つはセキュリティチェック用）を起動してプロジェクトをレビューするよう依頼するプロンプトを入力します。

![チャットでサブエージェントにプロンプトを送る](../../../assets/screenshots/sub-agents/6.png)

### ステップ 7: 送信して委譲を開始する

Enter キーを押すか送信ボタンをクリックしてクエリを実行します。Fabric は委譲コマンドを解釈し、特化したバックグラウンドのサブエージェントを起動して、その進行状況を表示します。

![送信して委譲を開始する](../../../assets/screenshots/sub-agents/7.png)

### ステップ 8: 統合された結果を待って読む

サブエージェントがバックグラウンドでの実行を完了するのを待ちます。完了すると、親エージェントが 3 つのレポートをすべて統合し、統一されたサマリーをチャットに表示します。

![統合された結果を待って読む](../../../assets/screenshots/sub-agents/8.png)

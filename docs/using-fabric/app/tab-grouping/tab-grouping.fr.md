## Qu'est-ce que le Regroupement d'onglets dans Fabric ?

Le Regroupement d'onglets dans Fabric offre un moyen flexible et visuellement intuitif d'organiser les onglets de votre espace de travail — y compris les sessions de chat actives, les fichiers de code et les instances de navigateur — en collections personnalisées et codées par couleur. Le regroupement aide à garder les contextes de projet associés rassemblés, réduisant la charge cognitive et l'encombrement de l'espace de travail.

Lorsqu'un groupe d'onglets est créé, Fabric lance automatiquement un service de nommage piloté par l'IA pour suggérer une étiquette descriptive basée sur le sujet des onglets actifs, tout en vous permettant de renommer, réduire, coder par couleur et gérer le groupe.


## Quand utiliser le Regroupement d'onglets dans Fabric

Utilisez le regroupement d'onglets dans Fabric lorsque vous souhaitez :

* **Isoler les contextes de fonctionnalité** : Garder les journaux de chat, les navigateurs de base de données et les éditeurs de fichiers pour des tâches distinctes (par exemple, « OAuth Setup » et « CSS Refactor ») organisés dans des groupes visuels séparés.
* **Regrouper les processus multi-agents** : Désencombrer votre barre d'onglets en regroupant une discussion d'orchestrateur parent avec tous les sous-agents en arrière-plan générés pour ce flux de travail.
* **Gérer la recherche web** : Garder ensemble plusieurs onglets de navigateur intégré avec les sessions d'invite (prompt) qu'ils accompagnent.


## Comment utiliser le Regroupement d'onglets dans Fabric

### Étape 1 : Ouvrir un deuxième onglet de chat

Cliquez sur l'icône plus (+) à droite de la barre d'onglets pour ouvrir une deuxième session de chat, fournissant plusieurs onglets à regrouper.

![Ouvrir un deuxième onglet de chat](../../../assets/screenshots/tab-grouping/1.png)

### Étape 2 : Clic droit sur un en-tête d'onglet

Faites un clic droit sur l'en-tête de l'onglet actif pour ouvrir le menu contextuel des options de l'onglet.

![Clic droit sur un en-tête d'onglet](../../../assets/screenshots/tab-grouping/2.png)

### Étape 3 : Sélectionner « Add to New Group »

Cliquez sur l'élément de menu « Add to New Group ». Cela crée un nouveau groupe d'onglets contenant l'onglet sélectionné.

![Sélectionner « Add to New Group »](../../../assets/screenshots/tab-grouping/3.png)

### Étape 4 : Inspecter le groupe généré

Un nouveau groupe d'onglets est créé avec une bordure gauche codée par couleur. Par défaut, le service générateur de noms intitule automatiquement le groupe en fonction du sujet de l'onglet.

![Inspecter le groupe généré](../../../assets/screenshots/tab-grouping/4.png)

### Étape 5 : Clic droit sur l'en-tête du groupe

Faites un clic droit sur l'en-tête coloré du groupe pour ouvrir le menu contextuel du groupe, exposant les options de personnalisation.

![Clic droit sur l'en-tête du groupe](../../../assets/screenshots/tab-grouping/5.png)

### Étape 6 : Personnaliser le nom et la couleur du groupe

Saisissez un nom descriptif (par exemple, « Research Workspace ») dans le champ de saisie en haut du menu contextuel, ou sélectionnez un autre échantillon de couleur pour personnaliser le thème du groupe.

![Personnaliser le nom et la couleur du groupe](../../../assets/screenshots/tab-grouping/6.png)

### Étape 7 : Choisir un échantillon de couleur de groupe

Sélectionnez un échantillon de couleur personnalisé dans le sélecteur pour coder visuellement l'en-tête du groupe.

![Choisir un échantillon de couleur de groupe](../../../assets/screenshots/tab-grouping/7.png)

### Étape 8 : Enregistrer vos personnalisations

Appuyez sur Entrée pour valider les modifications du nom et fermer le menu contextuel.

![Enregistrer vos personnalisations](../../../assets/screenshots/tab-grouping/8.png)

### Étape 9 : Afficher le groupe d'onglets terminé

Votre groupe d'onglets personnalisé est désormais configuré. Vous pouvez le réduire ou le développer en cliquant sur l'icône en chevron, y faire glisser des onglets supplémentaires ou fermer le groupe dans son ensemble.

![Afficher le groupe d'onglets terminé](../../../assets/screenshots/tab-grouping/9.png)

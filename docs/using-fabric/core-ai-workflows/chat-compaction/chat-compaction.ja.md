# チャットの圧縮

長い会話を続けるうちに、チャット履歴は大きくなり、それに伴ってトークン数も増えていきます。すべてのメッセージ、ファイル読み込み、ツールの結果は、モデルのコンテキストウィンドウに残ります。やがて上限に近づき、モデルは議論の早い部分を見失い始めます。

**圧縮**は、チャット履歴を簡潔な要約に圧縮することでこれを解決します。Fabric は会話全体を読み通し、重要な決定と結果を抽出し、すべてのやり取りを、重要な点を保持した短縮版に置き換えます。

---

## 仕組み

チャットツールバーの**圧縮**ボタンをクリックすると、Fabric は次のことを行います。

1. 現在の会話のすべてのメッセージを読み通します
2. 重要な決定、コードの変更、結論を特定します
3. 不可欠なコンテキストを捉えたコンパクトな要約を生成します
4. 冗長なチャット履歴をその要約に置き換えます

その結果、トークンのフットプリントが大幅に小さくなり、すでに達成した内容についてモデルに情報を与えたまま、新しいメッセージのためのスペースを確保できます。

## 圧縮ボタン

![圧縮ボタン](../../../assets/screenshots/compaction/compact-button.png)

**圧縮**ボタンは、チャットの入力欄のツールバー内、エージェントモードのコントロールとモデルセレクターの間にあります。会話中いつでもクリックして圧縮をトリガーできます。

---

## 圧縮を使用するタイミング

* **長時間にわたる会話** — 同じタスクに何十ものメッセージを費やして取り組んでいて、コンテキストウィンドウがいっぱいになりつつあるとき
* **大きな方向転換の前** — まったく新しい質問をしようとしていて、議論全体を引きずることなく、それまでの重要な結果を保持したいとき
* **レビューやデバッグのセッションの後** — やり取りが明確な結果（修正されたバグ、リファクタリングされたファイル）を生み出し、詳細な推論がもはや必要ないとき
* **インジケーターが黄色または赤に変わったとき** — Fabric のコンテキストウィンドウのインジケーターは、上限に近づくと警告します。圧縮は、コンテキストを失うことなくスペースを取り戻す最速の方法です

圧縮は、完全な会話がチャット履歴に依然として表示されるという意味では非破壊的です。ただし、*モデル*は以降、圧縮されたバージョンのみを見ることになります。これにより、両方の利点が得られます。自分のための読みやすいトランスクリプトと、AI のための効率的なコンテキストです。
